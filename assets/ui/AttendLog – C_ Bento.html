How a scan works

  1. Browser sends a camera frame to the server.
  2. HOG finds the face.
  3. A neural network makes 128 numbers.
  4. The closest saved face is picked. Above 0.6, it's "Unknown".
  5. PostgreSQL saves one record for the day.
